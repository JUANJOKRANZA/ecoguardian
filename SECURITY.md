# Seguridad y reporte de problemas

Este proyecto está en desarrollo y no debe exponerse públicamente como servicio de producción sin una revisión de seguridad.

- No publiques contraseñas, tokens, claves, archivos `.env`, bases de datos reales ni datos personales.
- Para informar de una vulnerabilidad, utiliza un canal privado con las personas mantenedoras del repositorio; no publiques detalles explotables en un issue público.
- Si un secreto se filtra, revócalo o cámbialo inmediatamente y revisa el historial del repositorio.
- Consulta `ESTADO_Y_LIMITACIONES.md` para conocer limitaciones técnicas pendientes.
